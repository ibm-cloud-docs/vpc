# Deploying a licensed firewall in your VPC
{: #licensed-firewall-vpc}

You can deploy a licensed next-generation firewall from the {{site.data.keyword.cloud_notm}} catalog to inspect and secure traffic that enters, leaves, and moves within your VPC. The licensing is applied automatically when the firewall is provisioned, so you don't need to purchase or manage licenses separately.
{: shortdesc}

Licensed firewall support for VPC is available for Fortinet FortiGate.
{: note}

## What is available
{: #licensed-firewall-vpc-available}

With the licensed firewall for FortiGate, you can deploy the following configurations:

* A single FortiGate virtual server instance
* An active/passive high availability (HA) pair in a single zone
* An active/passive HA pair across zones
