# Why can't I create a VPC or other VPC resources
{: #troubleshoot-cannot-create-1}
{: troubleshoot}
{: support}

You are unable to create a VPC or other VPC resources
{: shortdesc}

You are unable to create a VPC or other VPC resources
{: tsSymptoms}

You might not have the correct permissions to create vpc resources.
{: tsCauses}

Verify that the owner of the account has granted you the correct permissions
{: tsResolve}

If you cannot create a VPC or other resources, make sure that the owner of the account has granted you the correct permissions. For more information, see [Granting user permissions for VPC resources](/docs/vpc?topic=vpc-managing-user-permissions-for-vpc-resources#managing-user-permissions-for-vpc-resources) or [Authentication](/docs/apis/vpc/latest#api-authentication) in the VPC API content.

If you need more help after trying these steps, create a support case. For more information, see [Creating support cases](/docs/support?topic=support-open-case).
